# موارد لازم برای تأیید قرارداد لیارا

پیش‌نویس پرسش برای پشتیبانی یا برگزارکننده؛ ارسال نشده است. هیچ کلید یا اطلاعات خصوصی برای پاسخ لازم نیست.

## قیمت و موجودی

در `GET /v1/me`، فیلد `plans.projects[planID].price` و `plans.projectBundlePlans[planID][bundleID].displayPrice` موجودند. لطفاً تأیید کنید:

1. واحد پول و دوره هر فیلد چیست؟ آیا displayPrice قیمت فقط بسته است یا مجموع منابع و بسته؟
2. فرمول محاسبه هزینه واقعی ساعتی چیست؟ آیا تقسیم مبلغ ماهانه بسته بر ۷۲۰ معتبر است؟
3. قیمت‌ها شامل مالیات‌اند یا مالیات جدا اعمال می‌شود؟ نرخ مربوط به این حساب را از کدام API/صفحه رسمی باید خواند؟
4. واحد `GET /v1/billing → team.balance` تومان است؟ هزینه دیسک و سایر اقلام چگونه از قیمت پایه جدا می‌شود؟

پیش از پاسخ، فلگ `LIARA_PRICE_SCHEMA_VERIFIED` نباید صرفاً برای عبور از محدودیت فعال شود. اگر فرمول فعلی برنامه با پاسخ تأییدشده متفاوت بود، ابتدا فرمول و تست‌های آن اصلاح شوند.

## منابع

در `/v1/projects/{name}/metrics/cpu` و `/memory`، نمونه‌ها به شکل `[timestamp, value]` برمی‌گردند و schema عمومی واحد صریح ندارد:

1. CPU برحسب هسته مصرف‌شده، درصد یک هسته، یا درصد سهم پلن است؟
2. memory بایت است یا واحد دیگری؟ شامل چه نوع حافظه‌ای می‌شود؟
3. زمان نمونه‌ها، تأخیر معمول داده و بازه aggregation چیست؟
4. فیلدهای `cpuUsage` و `memoryUsage` در `/metrics/summary` چه واحد و بازه‌ای دارند؟

برای تبدیل به درصد پلن یا MiB باید این قرارداد روشن باشد. بزرگ‌بودن عدد یا شباهت آن به بایت دلیل کافی برای تعیین واحد نیست.

مراجع بررسی‌شده: [CPU](https://developers.liara.ir/pass/reports/get-cpu-reports-of-app)، [حافظه](https://developers.liara.ir/pass/reports/get-memory-reports-of-app)، [قیمت‌ها](https://liara.ir/pricing/). آخرین بازبینی: ۲۳ اکتبر ۲۰۲۶ به وقت تهران.
