# بررسی مریخ، مالیات و واحد منابع

۲۳ اکتبر ۲۰۲۶؛ خواندن API واقعی و پنل همان برنامه sample-node-app. هیچ خرید یا تغییر اندازه‌ای انجام نشد.

## قیمت واقعی برنامه

API، planID=medium-g2 و bundlePlanID=standard را برگرداند. منابع: RAM.amount=1، CPU.amount=1 با shared=true، volume=10. مقدار volume مدرک ساخت و اتصال یک دیسک پایدار نیست.

| ترکیب | منابع ماهانه | بسته ماهانه | مجموع ماهانه | با نرخ اعلامی مالک ۱۰٪ |
|---|---:|---:|---:|---:|
| مریخ + پایه | ۸۲۵٬۰۰۰ | ۴۷۵٬۰۰۰ | ۱٬۳۰۰٬۰۰۰ | ۱٬۴۳۰٬۰۰۰ |
| مریخ + نقره‌ای؛ فعال | ۸۲۵٬۰۰۰ | ۸۲۵٬۰۰۰ | ۱٬۶۵۰٬۰۰۰ | ۱٬۸۱۵٬۰۰۰ |

واحد جدول تومان است. مجموع ترکیب پایه با صفحه عمومی https://liara.ir/pricing/ و ترکیب نقره‌ای با صفحه تغییر اندازه پنل تطبیق داشت. بنابراین نباید ۱٫۳ میلیون را قیمت فقط منابع فرض کرد و بسته پایه را دوباره به آن افزود.

price ساعتی منابع 1145.83، پایه 659.72 و standard برابر 1145.83 است. برآورد ساعتی با نرخ ۱۰٪ به‌ترتیب 1986.105 و 2520.826 تومان است. پنل برای ترکیب standard عدد نمایشی ۲۲۹۰ تومان بدون مالیات نشان می‌دهد؛ عدد نمایشی گرد/قطع‌شده جای نرخ API نیست. گردکردن نهایی صورت‌حساب و اقلام اضافه مستقل بررسی نشده‌اند.

پنل صریحاً افزودن مالیات هنگام محاسبه را اعلام کرد، ولی نرخ عددی را در صفحه بررسی‌شده نمایش نداد. نرخ ۱۰٪ ورودی مالک است، نه کشف نرخ از API یا تأیید حقوقی. کنترل LIARA_PRICE_SCHEMA_VERIFIED و واحدهای متریک در env تغییر نکردند؛ این گزارش مجوز خودکار هزینه‌کرد نیست.

## CPU و حافظه

صفحه واقعی /apps/sample-node-app/monitoring بررسی شد. محور CPU درصد ۰،۵۰،۱۰۰ و محور RAM بایت/مگابایت دارد. این واحد نمایش پنل است؛ واحد raw API لزوماً یکسان نیست.

در نمونه خواندنی API، CPU حدود 0.000005 و memory حدود 27779072 بود. بایت‌بودن حافظه با اندازه حدود ۲۶٫۵ MiB نمودار سازگار است، ولی از بزرگی عدد به‌تنهایی قرارداد قطعی استنتاج نمی‌شود. برای CPU دو احتمال raw fraction/core و raw percent نتایج متفاوتی دارند. screenshot درصد پنل اثبات نمی‌کند که raw API نیازی به ضرب در ۱۰۰ ندارد. واحد دقیق CPU، نوع حافظه (RSS/working set)، نرمال‌سازی با ظرفیت و aggregation هنوز تأیید نشده‌اند؛ متغیرهای واحد unknown باقی ماندند. هیچ آستانه خودکار بر این حدس فعال نشد.

## تغییر و تست

محاسبه quote و رتبه‌بندی پلن اکنون از نرخ ساعتی مستقل منابع و بسته استفاده می‌کنند. تبدیل bundleMonthly/720 حذف شد؛ قیمت ناموجود یا نامعتبر مسدود می‌ماند. تست جدید جمع دو جزء، مالیات ۱۰٪، اختلاف گردکردن و رد NaN/منفی/نرخ نامعتبر را بررسی می‌کند. هر ۳۵ آزمون دستیار موفق شدند. شواهد خام محدود و بدون کلید در .local/mars-contract.json نگهداری می‌شوند و منتشر نمی‌شوند.

تست quote با قیمت زنده API در دیتابیس ایزوله نیز موفق بود: نرخ ساعتی 2520.826 و روزانه 60499.824 تومان با نرخ اعلامی مالک. transport همه درخواست‌های غیر GET را منع می‌کرد؛ تعداد نوشتن ریموت صفر بود و پیشنهاد محلی رد شد. فایل env اصلی و پلن سرویس تغییر نکردند. build ابتدا با محدودیت دسترسی esbuild در sandbox متوقف شد و سپس با اجرای مجاز موفق شد. گزارش این تست .local/mars-quote-test.json است.
